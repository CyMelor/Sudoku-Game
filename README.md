# 数独游戏

一个功能完整的数独游戏，支持多种难度和自动解题功能。

## 项目结构

```
Sudoku-Game/
├── css/
│   └── style.css          # 游戏样式文件
├── html/
│   └── index.html         # 游戏主页面
├── js/
│   └── script.js          # 游戏核心逻辑
├── app.py                 # 服务器启动脚本
└── README.md              # 项目说明文档
```

## 如何运行

1. 直接在浏览器中打开 `html/index.html` 文件

2. 或使用 Python 运行服务器脚本：

```bash
python app.py
```

然后在浏览器中访问 `http://localhost:15000`
